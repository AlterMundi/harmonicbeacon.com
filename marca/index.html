05 · La voz

Afirmativa, sobria, honesta

La honestidad epistémica es el activo de marca. Se vende una experiencia signature — no un dispositivo, no una teoría, no una cura. La promesa corta: “un viaje interior sonoro, sin sustancias, para presencia, descanso y sentido.”

✓ Decimos

  • experiencia de bienestar y exploración
  • campo armónico propio · escucha situada
  • presencia, calma, descanso, sentido
  • fase exploratoria · documentamos con cuidado
  • de origen psicoterapéutico → encuadre profesional
  • set and setting · no obligatoria · se puede pausar

✕ Evitamos

  • cura, tratamiento, terapia (sin negar), trauma
  • “regula el sistema nervioso” como mecanismo
  • frecuencias mágicas/sagradas, 432/528 Hz
  • cuántico, biocampo, detox, ADN
  • “técnica clínica”, claims médicos
  • seguridad absoluta · promesas grandiosas
